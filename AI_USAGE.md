# AI Usage Notes

## AI Tool Used

ChatGPT

---

## How AI Was Used

AI was used as a development assistant during this project.

It helped with:

- brainstorming the project idea
- suggesting API structure
- generating example test cases
- improving documentation wording

---

## Examples Where AI Helped

AI helped propose:

- a clean FastAPI project structure
- possible Pytest test cases
- documentation improvements for the README

All suggestions were reviewed and refined before being included in the final implementation.


## Where AI Output Was Corrected

Some AI suggestions were simplified to keep the project aligned with the assignment requirements.

Examples include:

- removing overly complex architecture ideas
- simplifying API logic
- refining tests to focus on behavior

## Code or Tests Written Without AI

The following parts were primarily written or finalized manually:

- final API route implementations
- test adjustments
- commit organization
- final documentation edits
